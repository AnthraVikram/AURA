# AURA 2.0

Personal command centre (Autonomous Unified Reasoning Assistant). Spec-driven first release.

## Setup

```bash
npm install
npm test
npm run dev
```

Validation scenarios: [specs/002-aura-foundation/quickstart.md](specs/002-aura-foundation/quickstart.md)

Data stays in this browser profile (`localStorage` key `aura.v1`). It is not synced to other devices.
